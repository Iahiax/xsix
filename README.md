# مرصاد — Unified Trading Intelligence

مرصاد لوحة عربية لقراءة بيانات Capital.com وتشخيص اتصال خدمات المشروع، مع واجهة مستقلة لنموذج المشروع المستضاف على Hugging Face Space.

## حدود التشغيل الحالية

- لوحة الوسيط والأسواق تقرأ بيانات Capital.com الحقيقية فقط عند نجاح تسجيل الدخول وطلبات المصدر. يمكن اختيار `live` أو `demo` عبر `CAPITAL_API_MODE`.
- طلب تسجيل الدخول إلى Capital.com ينشئ جلسة فقط؛ قراءة الحساب والمراكز والأسواق تتم عبر `GET`. لا توجد وظيفة لإرسال أمر، فتح مركز، إغلاقه، أو تعديله. المسارات القديمة للمحاكاة والإغلاق معطلة عمداً.
- لا تُستبدل بيانات الوسيط بأرقام تجريبية عند فشل الاتصال. تعاد حالة واضحة (`not_configured` أو `unavailable` أو `unauthorized`) وقيم مالية فارغة.
- أسعار الأسهم التي يطلبها قسم Finnhub منفصلة عن أسعار عقود Capital.com، ويعرض كل مصدر بوضوح. لا تُعرض مقاييس ربح أو تدريب أو نتائج تاريخية ما لم تتوفر بيانات حقيقية وتقييم قابل للتحقق.
- لا توجد أوزان مرصاد مدرّبة معتمدة في المستودع حالياً؛ لذلك قد تظل المحادثة متوقفة إلى أن تجهز نسخة المشروع وتنجح بوابة التقييم في Space الخاص. لا يوجد نموذج محادثة سحابي احتياطي.
- اتصال SSH لا يُعتبر ناجحاً لمجرد وجود إعداد؛ لا يُعرض نجاحه قبل وجود إعداد آمن وفحص فعلي.

## البنية

- `artifacts/trading-intelligence/`: واجهة React/Vite العربية.
- `artifacts/api-server/`: API Express وعميل Capital.com للقراءة فقط.
- `lib/api-spec/openapi.yaml`: عقد API؛ عميل المتصفح ومخططات التحقق مولّدة منه.
- `huggingface-space/`: تطبيق Python/Gradio وواجهات نموذج المشروع، التدريب، التقييم ومراقبة الأخطاء.
- `.env.example`: أسماء الإعدادات المطلوبة مع قيم إرشادية فقط. لا يحتوي أسراراً حقيقية.

## الإعداد المحلي

1. ثبّت الحزم باستخدام pnpm المتوفر في المشروع.
2. أضف القيم الجديدة إلى Replit Secrets أو إلى مدير الأسرار في بيئة التشغيل. لا تحفظ الأسرار في Git أو ملف `.env` مشترك.
3. لضبط Capital.com، أضف `CAPITAL_API_MODE` (`live` أو `demo`) و`CAPITAL_API_KEY` و`CAPITAL_IDENTIFIER` و`CAPITAL_PASSWORD`.
4. لإتاحة واجهة النموذج، اضبط `LOCAL_MODEL_URL` و`LOCAL_MODEL_ID` و`LOCAL_MODEL_API_TOKEN` و`LOCAL_MODEL_HF_TOKEN` كما هو موضح في `huggingface-space/README.md`.
5. شغّل فحوص المشروع:

```bash
pnpm -w run typecheck
pnpm --filter @workspace/api-spec run codegen
pnpm --filter @workspace/api-server run test
python -m unittest discover -s huggingface-space -p 'test_*.py'
bash huggingface-space/preflight.sh
```

اختبار API يستخدم بيانات اختبار محلية ولا يتصل بحساب Capital.com حقيقي. ينبغي إجراء التحقق الحي يدوياً بعد إدخال أسرار جديدة؛ لا تُرسل قيم الأسرار إلى المحادثة.

## تجهيز Hugging Face Space

- استخدم `huggingface-space/` كتطبيق Space مستقل بلغة Python؛ ارفع محتويات المجلد إلى جذر مساحة Gradio، لا المجلد نفسه.
- ملف `README.md` في الجذر مهم: يحتوي ترويسة Space (`sdk: gradio`, `python_version`, `app_file`) التي يقرأها Hub لإعداد البناء.
- لا تختَر Docker. Space المجاني مع ZeroGPU لا يبقى مستيقظاً طوال الوقت؛ قد يتوقف عند الخمول، وحصة GPU محدودة، لذلك لا يصلح كخادم محادثة أو تداول دائم.
- أضف الأسرار من إعدادات Space، ولا ترفع `.env` أو مفاتيح أو بيانات حساب أو أوزان خاصة إلى المستودع.
- ملفات إعداد Space لا تعني أن التدريب اكتمل: لا توجد حتى الآن أوزان مرصاد معتمدة ولا اختبار GPU فعلي على حساب المستخدم. التدريب والترقية اليدويان لا يبدآن إلا بعد توصيل البيانات والأسرار واستيفاء بوابات التقييم.
- قبل الرفع شغّل `bash huggingface-space/preflight.sh` واختبارات Python أعلاه.

## مختبر التداول الكمي في Hugging Face Space

- تطبيق الـSpace داخل `huggingface-space/` مكتوب ببايثون وGradio، ويجلب شموع Capital.com من بيئة Demo فقط.
- يشمل RSI وMACD وATR وSuperTrend والزخم والتقلب، وشبكة MLP صغيرة متعددة الطبقات، ووكيل Q-learning بحثياً، واختباراً زمنياً خارج العينة مع bid/ask فعليين وحدود مخاطر.
- لا يرسل التطبيق أوامر تلقائية ولا يدعم وضع Capital.com الحي. إرسال Demo يدوي منفصل، ومقفول افتراضياً، ويتطلب دخول Hugging Face مخولاً وتفعيل إعدادات صريحة.
- SQLite يحفظ الشموع والتقارير محلياً أثناء عمل Space؛ مساحة Hugging Face المجانية لا تضمن بقاء الملفات أو التشغيل بعد الخمول. لا توجد بيانات اصطناعية بديلة.
- لم يُنفّذ تدريب GPU فعلي أو اختبار أداء على حساب Hugging Face بعد، ولم تُنشأ أوزان محادثة مرصاد معتمدة.

## بيانات الاتصال والأمان

- تُعرض معرفات الحساب والصفقات بعد إخفاء معظمها، ولا تعاد رموز جلسة Capital.com إلى المتصفح.
- تُحفظ جلسة الوسيط مؤقتاً في ذاكرة خدمة API، وتُستخدم لإجراء طلبات القراءة فقط. إعادة تشغيل الخدمة تمحو الجلسة المؤقتة.
- إذا فشل المصدر، افحص قسم الموصلات ورسائل API؛ لا تفسّر وجود مفتاح في الأسرار على أنه اتصال ناجح.
- لتدوير قيمة سبق مشاركتها في رسالة، ألغها لدى مزودها وأنشئ قيمة جديدة، ثم أدخلها في مدير الأسرار. لا تعاود إرسالها في المحادثة.
